Riot Vanguard

Replays from patch 14.9 on need Vanguard running. Older patches play without it.

...

L-Recall only reads Vanguard's status. It never starts, stops or changes it. If an old replay crashes, exit Vanguard from its own tray icon (it comes back when you restart), which is the way Riot supports.
