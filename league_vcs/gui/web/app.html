General

Riot ID?

So wins, losses and your champion show from your side.

Replay folders

Where your replays (.rofl files) are. Folders inside these count too.

Saving patches

An old replay only plays on its own patch, so L-Recall saves a copy of each patch from your League install when Riot updates.

League installs?

Where patches get saved from.

Save new patches automatically

When it's off, nothing gets saved until you hit Save it now on the Patches tab.

Storage folder?

Where saved patches are kept. Pick a drive with room.

If something's wrong

Check storage

Makes sure every saved patch still matches the original game files. Safe to stop.

Rearrange storage

Tidies the saved files so patches get ready faster. Takes a few minutes, safe to stop.

Watching replays

Before a replay plays, its saved patch gets unpacked so League can run it. That's the ready patch. It takes half a minute to a few minutes, depending on your drive.

Only unpack what the replay needs?

Around 5 GB instead of 30, and replays start sooner.

Patches kept ready?

Each extra one takes several GB.

Get the newest patch ready in the background

So your latest replays start sooner. Only while you're not playing.

Use my League settings

Your graphics, camera and hotkeys instead of the game's defaults.

Clear ready files when L-Recall closes

Gets the space back. The next replay takes a bit longer to start.

Drive type?

Changes how patches get unpacked. Leave it on Auto unless it guessed wrong.

Icons

The champion and item pictures. Kept on your PC so they show up fast, even offline.

Riot Vanguard

Riot's anti-cheat. If it's running all the time, replays won't open.

Status

...

Use Pre-Check if you can

Vanguard then only switches on while a game's running, so replays open fine. Without it, exit Vanguard from its tray icon before watching.

L-Recall only reads Vanguard's status. It never changes it or tries to get around it.

Problem report

Something broken? Zips your recent logs into Downloads, with your username taken out, so you can send them to whoever's helping.

Uninstall

Uninstall L-Recall
